## Local Development

Clone the repository:

```bash
git clone https://github.com/mgordon82/professional-portfolio.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the static site (outputs to `out/`):

```bash
npm run build
```
